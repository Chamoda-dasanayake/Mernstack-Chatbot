## 📌 Overview

A production-ready full-stack AI chatbot system built using the MERN stack and integrated with Google Gemini AI.  
This project demonstrates real-world software engineering including authentication, AI integration, database design, and AWS deployment.

---

## ✨ Key Features

- 🤖 AI-powered conversations using Google Gemini
- 🔐 Secure authentication (JWT + HTTP-only cookies)
- 💾 Persistent chat history using MongoDB
- 🎨 Modern UI built with React + Material UI
- ⚡ Scalable backend architecture with Express
- ☁️ Production deployment on AWS EC2

---

## 🛠️ Tech Stack

**Frontend:** React.js, TypeScript, Material UI, Vite  
**Backend:** Node.js, Express.js  
**Database:** MongoDB Atlas  
**AI Model:** Google Gemini Pro  
**Auth:** JWT, HTTP-only cookies  
**Deployment:** AWS EC2, Nginx, PM2  
**Version Control:** Git, GitHub  

---

## 🏗️ Architecture

User → React Frontend → Express API → Gemini AI → MongoDB → Response

AWS Layer:
- EC2 Ubuntu Server
- Nginx Reverse Proxy
- PM2 Process Manager

---

## 🚀 Deployment Setup

- Frontend hosted via Nginx on EC2
- Backend managed using PM2
- API requests routed via Nginx reverse proxy
- MongoDB Atlas for cloud database
- AWS security groups configured for HTTP traffic

---

## 🔄 API Endpoints

- POST `/api/auth/register`
- POST `/api/auth/login`
- POST `/api/chat/send`
- GET `/api/chat/history`
- DELETE `/api/chat/clear`
